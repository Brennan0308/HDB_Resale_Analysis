# HDB Resale Dashboard (SQL Analysis 5 - Dashboard Edition)

This Power BI dashboard presents the **Average % Appreciation**, **Resale Price**, and **Appreciation Value** of Singapore HDB flats after their 5-year MOP (Minimum Occupation Period), covering the years **2017 to 2019**. It is derived from `SQL_Analysis_5_HDB_BTO_Price_Appreciation_After_MOP`.

---

## Dashboard Features

- **Key Metrics Cards**
  - Average % Appreciation (Overall)
  - Average Resale Price
  - Average Appreciation Value

- **Clustered Column Chart**
  - Shows Average % Appreciation across 3-Room, 4-Room, and 5-Room flat types
  - Breakdown by Year (2017, 2018, 2019)
  - Dynamic interaction with town-level filters

- **Slicer by Town**
  - Filter results by towns such as Punggol, Sembawang, Yishun, etc.
  - Enables localized comparison of resale performance

---

## Objective

To visualize the appreciation performance of HDB resale flats post-MOP and understand how different flat types and towns have performed over the years. This supports better decision-making for prospective buyers or analysts.

---

## Tools Used

- SQL: For data wrangling and analysis (`SQL_Analysis_5`)
- Power BI: For interactive dashboard visualization
- DAX: Custom measures for average % appreciation and max highlight logic
